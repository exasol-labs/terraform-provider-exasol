# Exasol Provider

The Exasol provider manages [Exasol](https://www.exasol.com/) database resources as code: schemas, external connections, users, roles, and privileges/grants. It is built on the Terraform Plugin Framework and the official [exasol-driver-go](https://github.com/exasol/exasol-driver-go).

!> **Warning:** This is an open source project not officially supported by Exasol. We will try to help you as much as possible, but can't guarantee anything since this is not an official Exasol product.

## Installation

Add the provider to your configuration and run `terraform init`:

```terraform
terraform {
  required_providers {
    exasol = {
      source  = "exasol-labs/exasol"
      version = "~> 0.2"
    }
  }
}
```

## Authentication

Authenticate with a username and password, or with an Exasol Personal Access Token (PAT) supplied in the `password` field (tokens prefixed with `exa_pat_` are detected automatically). For Exasol instances with a self-signed certificate (for example a local Docker container), set `validate_server_certificate = false`.

## Example Usage

```terraform
provider "exasol" {
  host     = "exasol.example.com"
  port     = 8563
  user     = "sys"
  password = "exasol"

  # Set to false for self-signed certificates (e.g. Docker containers)
  validate_server_certificate = true
}

# PAT token authentication (detected automatically by exa_pat_ prefix)
provider "exasol" {
  alias    = "pat"
  host     = "exasol.example.com"
  user     = "my_user"
  password = "exa_pat_abc123..."
}
```

## Schema

### Required

- `host` (String) Exasol host (DNS or IP).
- `password` (String, Sensitive) Exasol password or Personal Access Token (PAT). Tokens starting with exa_pat_ are detected automatically.
- `user` (String) Exasol username.

### Optional

- `connect_timeout` (Number) Total time in seconds to keep retrying the initial connection on network errors before failing. Useful when an IP allowlist entry needs time to propagate. 0 disables retrying (single attempt). Default 60.
- `port` (Number) Exasol port. Default 8563.
- `validate_server_certificate` (Boolean) Validate server TLS certificate. Default true.
